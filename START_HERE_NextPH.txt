NextPH implementation documentation bundle

Files:
- NextPH_Project_Documentation.docx: editable, formatted technical specification
- NextPH_Project_Documentation.md: plain-text/Markdown specification for AI coding agents
- NextPH_AI_Builder_Prompt.md: standalone build prompt to run alongside the full specification

Recommended use:
1. Give the AI coding agent the Markdown specification and the standalone prompt.
2. Ask it to inspect the repository and official docs, then implement the specification in small phases.
3. Do not give the agent production secrets or unattended write access to production Cloudflare/WordPress resources.
4. Replace the reserved example domains, pick a newsletter provider, and provision WordPress hosting before launch.
